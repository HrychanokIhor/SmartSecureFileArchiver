# SmartSecureFileArchiver

Навчальний командний архіватор на .NET 10. Проєкти: CLI, Core, Tests.
CLI наразі є каркасом; повний цикл SARC ще не інтегровано.

## Huffman

Реалізовано канонічний Huffman, байтовий адаптер IHuffmanCoder та три
незалежні алфавіти для літералів/маркерів, довжин і відстаней LZ77.

[Повний розбір коду, API, складність і приклади](docs/HUFFMAN.md).

Формат HUF1 попередній: FORMAT_SPEC_P2.md викладача ще не надано.
Сумісність з еталонними архівами не підтверджена.
Використання генерації коду задекларовано в [META-USAGE](META-USAGE).

## Перевірка

Потрібен .NET SDK 10. Із кореня репозиторію:

```sh
dotnet test SmartArchiver.slnx
```
