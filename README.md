# SmartSecureFileArchiver

Навчальний командний архіватор на .NET 10. Проєкти: CLI, Core, Tests.
CLI читає та записує однофайловий архів SARC v1 з одним томом.
`pack <вхідний_файл> <архів.sarc> <пароль>` створює том до 64 КіБ;
`unpack <архів.sarc> <вихідний_файл> <пароль>` перевіряє HMAC, розміри і CRC32.
Для запису використовуються блоки до 16 КіБ і режим без стиснення,
якщо стиснутий блок не менший за сирі дані.
Багатофайлові та багатотомні архіви й попередні експериментальні архіви HUF1
цим CLI не підтримуються.

## Huffman

Реалізовано канонічний Huffman, байтовий адаптер IHuffmanCoder та три
незалежні алфавіти для літералів/маркерів, довжин і відстаней LZ77.

[Повний розбір коду, API, складність і приклади](docs/HUFFMAN.md).

SarcPipeline використовує [формат стиснутого блока SARC v1](docs/SARC-V1-BLOCKS.md).
HUF1 залишається окремим експериментальним форматом. Повний формат тому ще потребує інтеграції.
Використання генерації коду задекларовано в [META-USAGE](META-USAGE).
